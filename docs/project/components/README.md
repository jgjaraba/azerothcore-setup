# Components

One document should describe each project subsystem whose durable behaviour,
customizations or constraints are important to future work.

Component documents are maintained from verified inspection. The component
catalog and the focused Playerbots ecosystem/custom world SQL documents reflect
the 2026-09-19 source-level audit.

Cross-component identifier ownership is documented in `../CUSTOM-IDENTIFIERS.md`;
durable risks are recorded in `../debt/REGISTER.md`.

Do not create speculative component documentation.
