# Features

One document per project feature whose behavior, ownership and contracts must
survive the original task.

Feature documents describe the durable design and implementation contract of
custom content. They are not task logs: progress, validation transcripts and
intermediate design iterations belong nowhere in this knowledge base.

Current features:

- [`forsaken-paladin-class-quests.md`](forsaken-paladin-class-quests.md) — the
  Undead Paladin class-quest chains, their item/DBC contract and their loot
  conditions.

Identifier ownership for these features is recorded in
[`../CUSTOM-IDENTIFIERS.md`](../CUSTOM-IDENTIFIERS.md); the module and database
context is in [`../components/`](../components/).
